Lunlun Launcher

APK ダウンロード

ここから APK を取得して、Android 端末で開いてインストールしてください。 ファイル名は lunlun-launcher.apk です。

Download APK Install steps

ダウンロードが始まらない場合は Download APK を押してください。

File lunlun-launcher.apk
Build Debug
Target Android 8.0+

Install steps

  1. Tap Download APK.
  2. Open the downloaded file from the browser or the downloads app.
  3. Allow installation from this source if Android asks.
  4. Finish the installer and launch Lunlun Launcher.
